# CodeTree — Python 문제 풀이 기록

CodeTree 문제를 풀며 Python 입출력, 배열, 구간 처리, 탐색을 연습한 저장소입니다. 문제별 폴더에 설명과 Python 풀이를 보관합니다.

## 학습 구성

| 폴더 | 포함된 연습 |
| --- | --- |
| [trail1](trail1/) | 출력·입력, 변수, 문자열, 배열의 합·평균·특정 위치 탐색 |
| [trail2](trail2/) | 블록 쌓기, 겹치는 구간, 흰색·검은색 칠하기 |
| [trail4](trail4/) | 중복 순열 생성, 마을 구분 탐색 |

일부 문제 폴더에는 설명만 있습니다. 폴더 수를 제출 성공 횟수나 정답 수로 해석하지 않습니다.

## 풀이 실행

Python 3으로 해당 풀이 파일을 실행하고, 문제 설명에 맞는 입력을 전달합니다. 공백이 있는 경로는 따옴표로 감쌉니다.

```sh
python "trail4/마을 구분하기/seperate-village.py"
```

문제 조건과 입력 예시는 각 폴더의 README에서 확인합니다. 각 풀이는 독립적인 프로그램입니다.

## 기록 범위

현재 저장소는 풀이 코드 중심의 학습 기록입니다. 자동 채점 결과 전체나 공통 테스트 체계는 포함하지 않습니다. 이후 풀이별 접근 이유·시간 복잡도·실수한 입력 사례를 추가하면 학습 과정을 더 명확하게 남길 수 있습니다.
